# NetOps Hub on iOS (iPhone / iPad)

برای اجرای NetOps Hub روی سیستم‌عامل **iOS (آیفون و آیپد)** به دلیل سیاست‌های انحصاری اپل، از فناوری رسمی **Progressive Web App (PWA)** که توسط موتور WebKit سافاری پشتیبانی می‌شود استفاده می‌شود:

### راهنمای نصب روی آیفون / آیپد (iOS):
1. در آیفون یا آیپد خود، مرورگر **Safari** را باز کنید.
2. آدرس ابری کلودفلر اپلیکیشن را وارد کنید:
   ```text
   https://netops-hub-api.mortavox.workers.dev/
   ```
   یا آدرس پورتال تحت وب AI Studio:
   ```text
   https://ais-dev-ernk332rj7qq55q6oohure-200130467355.europe-west2.run.app/
   ```
3. در نوار پایین مرورگر سافاری روی آیکون **Share (اشتراک‌گذاری / مربع با فلش رو به بالا)** کلیک کنید.
4. گزینه **Add to Home Screen (افزودن به صفحه اصلی)** را انتخاب کنید.
5. آیکون برنامه اختصاصی NetOps Hub روی صفحه اصلی گوشی شما مانند یک اپلیکیشن بومی iOS ظاهر می‌شود و بدون نوار آدرس مرورگر به صورت تمام‌صفحه و با سینک لحظه‌ای Cloudflare D1 اجرا خواهد شد.
