# NetOps Hub on Windows

You can run NetOps Hub natively on **Windows 10 / Windows 11** using any of the following standard methods:

### روش ۱: استفاده از Windows Subsystem for Android (WSA) - بهترین کیفیت و اجرای Native
1. در ویندوز ۱۱، قابلیت **Windows Subsystem for Android** را نصب کنید.
2. وارد تنظیمات WSA شده و گزینه **Developer Mode (حالت توسعه‌دهنده)** را فعال کنید.
3. فایل نصبی `NetOpsHub.apk` را با استفاده از برنامه رایگان **WSA-PacMan** باز کنید یا فایل `install-wsa.bat` را اجرا نمایید.
4. اپلیکیشن مستقیماً مانند یک نرم‌افزار مستقل ویندوزی در منوی استارت و تسک‌بار قرار می‌گیرد.

### روش ۲: استفاده از شبیه‌سازهای ویندوز (BlueStacks / LDPlayer / Nox)
1. نرم‌افزار BlueStacks یا LDPlayer را روی ویندوز باز کنید.
2. فایل `NetOpsHub.apk` را داخل برنامه Drag & Drop کنید تا فوراً نصب و اجرا شود.

### روش ۳: وب‌اپلیکیشن اختصاصی تحت کلودفلر (بدون نیاز به نصب)
- آدرس پورتال ابری NetOps Hub را در مرورگر Edge یا Chrome باز کرده و به صورت مستقیم از تمام ابزارها و دیتا استفاده کنید.
